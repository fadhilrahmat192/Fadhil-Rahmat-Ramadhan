## 💻 Cara Menjalankan Secara Lokal

1. Clone repositori ini:
   ```bash
   git clone https://github.com/fadhilrahmat192/Fadhil-Rahmat-Ramadhan.git
   ```
2. Buka folder proyek:
   ```bash
   cd "Resume FR - Website"
   ```
3. Buka file `index.html` langsung di browser, atau jalankan server lokal sederhana:
   ```bash
   # Menggunakan Python:
   python -m http.server 8080
   
   # Atau menggunakan Node / npx:
   npx serve .
   ```
4. Buka `http://localhost:8080` di peramban Anda.
